/* index.css — one utility for every clickable card */
.card-interactive {
  cursor: pointer;
  position: relative;
  transition:
    transform .28s cubic-bezier(.34, 1.56, .64, 1),
    box-shadow .28s, border-color .28s;
}
.card-interactive:hover {
  transform: rotate(-1.2deg) scale(1.025);
  border-color: #C2654A;               /* tomato */
  box-shadow: 0 14px 28px -10px rgb(194 101 74 / .35);
}
.card-interactive .card-go {           /* <span class="card-go">Explore →</span> */
  position: absolute; right: 1.1rem; bottom: .95rem;
  font-size: .8rem; font-weight: 600; color: #C2654A;
  opacity: 0; transform: translateX(-8px);
  transition: opacity .18s ease, transform .18s ease;
}
.card-interactive:hover .card-go { opacity: 1; transform: translateX(0); }
.card-interactive:focus-visible {      /* keyboard parity */
  outline: 2px solid #C2654A; outline-offset: 2px;
}
@media (prefers-reduced-motion: reduce) {
  .card-interactive, .card-interactive .card-go { transition: none; }
  .card-interactive:hover { transform: none; }
}

Buttons & small elements

Tabs and chips shouldn't do the full plate-pickup — the complementary rule: cards lift, buttons press, tied together by the same spring curve and terracotta accent. Hover each row (first pill is the active tab, which stays put).

B1 · Press-down ★

Squishes to 96% with a terracotta tint — feels like a physical button, opposite of the cards' lift.

B2 · Simmer bounce

Springs up 7% with a 1° tilt — same personality as the cards, spunkiest option. Can feel busy next to lifting cards.

B3 · Fill sweep

Terracotta tint sweeps in from the left, previewing the selected state. Calm, no movement.

B4 · Underline garnish

Text warms to terracotta and a small underline grows — echoes the card title underline. Most editorial.
